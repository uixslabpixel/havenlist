Hvnlst design system

One stylesheet, design-system.css, holds every token and shared component. Pages only add layout on top; they never restyle a component.

Colour Typography Radius & elevation Spacing & motion Buttons Text links Inputs Chips & filters Pagination Cards Feedback

Colour

Ink is the only text colour. Lighter text, hairlines and fills are ink at a fixed alpha, so everything stays in one tone.

Typography

Inter Display for headings and titles, Geist for interface text. Display text uses −0.02em tracking, UI text −0.01em.

Radius & elevation

Controls are pills; cards and panels use 24px; media inside a card uses 16px. Shadows stay soft and low.

Spacing & motion

A 4px base. Page edges use --page-pad (64px, 24px on phones); controls are --control-h (40px) tall.

Buttons

One button component, .hl-btn, in two tones. Hover reveals the label letter by letter; white buttons also fill with the hover veil.

Primary and secondary

.hl-btn.hl-btn--black · .hl-btn.hl-btn--white · add .hl-btn--lg for hero calls to action

Icon buttons

.icon-btn (navbar / detail actions) · .ui-btn (round arrow) · .ui-btn--raised for “view all” links

Text links

Every text link and text button uses the same letter reveal on hover (rise.js). Arrow links draw their stroke.
